Project 01

天穹网链：面向应急通信的具身智能无人机通信组网技术

背景

灾害或复杂地形场景下，地面通信基础设施可能受损，需要快速建立临时通信链路。

问题

无人机节点具备机动性，但组网稳定性、任务分配、链路恢复和方案说明都需要被清晰设计。

我的角色

参与方案资料整理、系统逻辑梳理、PPT 表达和交付材料组织，重点负责把技术路线讲清楚。

方案

围绕“空中节点部署、链路协同、故障感知、备用路径”搭建项目叙事，并用流程图表达关键机制。

关键产出

形成项目汇报页、系统架构图、应用场景说明和阶段性成果展示图。

能力体现

把偏技术的通信组网项目转成面向评审和合作方可理解的方案，兼顾技术准确性和表达效率。

Project 02

校园小游戏《我的外卖被偷了》

项目背景

外卖错拿、被拿走、沟通成本高，是校园生活里很具体的小场景。我们把它做成一个轻量互动小游戏，让玩家用更轻松的方式进入故事。

核心问题

项目不能只停在“有趣的梗”，还要有清楚的行动路径、反馈机制和展示结果，让玩家知道每一步选择为什么会影响结局。

我的角色

产品策划 / 玩法设计 / 文案设计 / 视觉与展示统筹，主要负责把场景、玩法、文案和最终展示串成完整体验。

解决方案

围绕“校园外卖被偷”设计三步行动选择：在校园地图中收集线索、与角色互动、判断事件走向，最后生成个性化的结局报告与搭子报告。

关键产出

完成游戏流程、核心文案、展示页内容、项目汇报材料和可下载试玩 Demo，便于面试官快速理解项目形态。

能力体现

这个项目更像一次小型产品落地练习：从真实场景切入，控制功能范围，组织玩法节奏，并和视觉、展示材料一起交付。

Project 03

二手交易平台“高校专区化”需求验证与盈利空间调研

背景

高校二手交易有明显的地理集中、信任关系和季节性需求，但通用平台对校园场景支持有限。

问题

需要判断“高校专区”是否真的有需求，以及它可能通过哪些方式提升交易效率或产生商业空间。

我的角色

参与调研框架设计、问卷与访谈信息整理、竞品观察、结论归纳和报告表达。

方案

从用户痛点、供需频次、信任机制、平台功能和变现路径五个角度拆解问题。

关键产出

输出需求验证报告、用户画像、功能优先级建议、盈利空间假设和汇报材料。

能力体现

能把“我觉得有用”的想法推进到“证据是否支持、可以先做什么、风险在哪里”。

Project 04

葡萄酒类别识别数据挖掘项目

背景

葡萄酒数据集包含多项化学指标，适合用来练习分类建模、特征理解和结果解释。

问题

模型不只是跑出准确率，还要说明哪些特征有效、不同类别差异在哪里、结果是否可信。

我的角色

负责数据清洗、探索性分析、模型训练、可视化结果整理和报告撰写。

方案

使用 Python 完成数据概览、特征分布、相关性分析、分类模型对比和混淆矩阵解释。

关键产出

形成 notebook、分析报告、特征图表、模型评估结果和可复用的项目总结页。

能力体现

能把数据挖掘流程讲成清晰的问题解决过程，并把技术结果转成非技术同学也能理解的结论。
